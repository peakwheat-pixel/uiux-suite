# 发现与基线（G0/G1）

## 目标

在不修改生产源码、不碰真实用户数据的前提下，建立可复核的现状基线。

## 步骤

1. 记录技术栈（web / tauri / qt / winui / wpf）与项目根；确认 target scope。
2. 列出窗口/页面/路由/命令与入口；标注不在范围内的区域。
3. 采集基线证据：截图（进 Vault）、实际显示尺寸、DPI、主题、语言。
4. 记录源码指纹：Git commit 或非 Git 目录摘要（`dir_digest`）。
5. 清点已知缺陷与用户报告的问题；区分 UI、UX、性能、数据安全。

## 产出

- 基线清单（页面/窗口/任务）
- `source_fingerprint`
- 证据引用（`evidence-manifest` 登记）
- 已知问题列表（带场景 ID）

## 红线

- 不写生产源码；测试数据复制到沙箱。
- 截图等私密原件只进 Vault，交付用脱敏摘要。
- 缺失环境时记 `UNVERIFIED`，不编造基线。
