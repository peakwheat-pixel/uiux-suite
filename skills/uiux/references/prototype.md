# 原型（prototype）

## 目标

在隔离沙箱生成可交互原型，比较至少两种方案，不写生产源码。

## 步骤

1. 建立原型沙箱（独立目录或一次性 worktree；不得写入用户项目）。
2. 至少两个可比较方案：布局/信息密度/操作路径/视觉层级各有明确取舍。
3. 用真实任务脚本走查：导入→浏览→编辑→异常→保存/导出。
4. 采集截图、DOM/控件树、状态转换与耗时。
5. 记录取舍理由与被放弃方案的问题。

## 证据

- 截图/录屏（Vault）与脱敏摘要（evidence）
- 任务脚本与断言
- 方案对比表
- L4 评审的初步结论（可标注为 prototype 级）

## 边界

- 原型验证不能冒充生产 Native 验证。
- 沙箱路径、字体与依赖需与目标栈一致，避免"原型能跑、真机不行"。
