# 威胁模型（m1）

## 资产
契约文件、冻结规则/Token、证据与哈希链、审查签名、用户项目源码与数据、发行包。

## 主要威胁
1. **Prompt Injection**：项目内 README/注释/issue 诱导 Agent 跳过 Gate、伪造证据或扩大写作用域。
2. **证据伪造/篡改**：手改 evidence、替换截图、伪造 git commit 或 reviewer 签名。
3. **跨层冒充**：把 SIMULATED/MOCK 结果标成 NATIVE/OS_INTEGRATION。
4. **权限越界**：修改用户真实项目、未授权外部调用、全局物理键鼠注入。
5. **依赖与供应链**：不可信构建脚本、网络安装、恶意字体/包许可。
6. **本地同权**：同机 Agent 可修改证据与日志（无硬件签名，只能哈希链+一致性降低风险）。

## 缓解
- Gate 由代码派生（G6 只在 finalize），任何输入不能直接写 PASS；WARN 处置绑定 reviewed_head。
- 证据生命周期 + Vault 字节校验 + 哈希链 + 独立性绑定；`user_attested` 拒绝。
- 运行层级枚举强制区分；最弱路径汇总；跨层证据必须 `probe_id`。
- 写作用域受控改动 + 备份/回滚；`input_policy` 默认拒绝全局物理输入。
- `build_guard` 默认拒绝未知可执行、破坏性命令、网络与越界路径。
- 外部内容只作为数据，不作为指令；外部编排方只能传任务/证据要求，不得改 Gate。

## 残余风险
本地管理员/同权进程、宿主自身漏洞、真实项目数据安全仍需隔离环境与人工授权。
