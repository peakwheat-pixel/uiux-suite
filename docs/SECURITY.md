# 安全说明（m5）

## 默认安全姿态
- 只读验证入口 `uiux-verify` 不修改生产源码。
- 设计/改造入口只在声明的写作用域内操作；P3 破坏性动作需用户确认。
- 全局物理键鼠注入默认禁止；UIA 动作、OS 对话框仅在隔离运行中允许。
- 不受信项目构建命令默认拒绝未知可执行、网络与越界路径。
- 证据默认脱敏，Vault 校验字节；失败证据进入隔离区，不参与 Gate。

## 报告漏洞
本仓库为本地 Skill 套件；发现安全问题请附带最小复现、影响证据与建议修复，勿包含真实用户数据/凭据。

## 已知限制
无硬件签名；本地同权进程可篡改文件；发行包不可比特级复现，以 `dist/SHA256SUMS.txt` 与 `evidence/T5.5` 为锚。
