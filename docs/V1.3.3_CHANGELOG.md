## 3. 关键语义变更

1. **G6 转为 finalize 派生结果**，不再作为输入 Gate；输入含 G6 被 Schema 拒绝。
2. **WARN_REVIEW_REQUIRED 必须绑定处置记录**（finding、评审来源、reviewed_head、expiry、证据）。
3. **COMPLETE 与 INDEPENDENT_REVIEW_PASS 解耦**：只有模式/交付层级/profile 要求独立验收时才强制。
4. **audit 的 G4 统一为 REVIEW_ONLY**，消除 "矩阵 —" 与 "audit 只读检查" 的冲突。
5. **targeted-fix 的 G2 改为 MANDATORY**，避免条件必选缺少触发条件。
6. **运行层级取最弱必选路径**；单点 Native PASS 不提升整体等级。
7. **suite-link 相对定位允许 `..`**（`relative_locator`），跨盘/UNC 使用绝对路径。
8. **删除主动依赖外部编排器的条款**；仅保留 `caller.kind=external` 的被动传参与边界约束。
