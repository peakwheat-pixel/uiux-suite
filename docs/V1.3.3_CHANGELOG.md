## 3. 关键语义变更

1. **G6 转为 finalize 派生结果**，不再作为输入 Gate；`gates.G6` 或顶层 `g6` 均被 Schema 拒绝。
2. **WARN_REVIEW_REQUIRED 必须绑定处置记录**（finding、评审来源、`reviewed_head`、expiry、证据），CLI 独立文件与内嵌记录走同一 Schema。
3. **COMPLETE 与 INDEPENDENT_REVIEW_PASS 解耦**；有效 `ISOLATED_SESSION` 审查可产生 `ISOLATED_REVIEW_VERIFIED`。
4. **production-code 的 L4 必须独立**：由 `deliverable_tier` 派生，与运行级 `independent_required` 分离。
5. **audit 的 G4 统一为 REVIEW_ONLY**，消除 "矩阵 —" 与 "audit 只读检查" 的冲突。
6. **targeted-fix 的 G2 改为 MANDATORY**，避免条件必选缺少触发条件。
7. **运行层级取最弱必选路径**；单点 Native PASS 不提升整体等级；coverage 自报层级必须与 provenance/tool-log 一致。
8. **request_digest 绑定**：`gate-results.request_digest` 与当前请求不一致 → `REQUEST_DIGEST_MISMATCH`，阻断事后调低 `runtime_targets`。
9. **FAILED 语义统一**：MANDATORY/REVIEW_ONLY Gate FAIL 或 L4 FAIL 均输出 `FAILED`，不再降级为 `PARTIAL`。
10. **删除主动依赖外部编排器的条款**；仅保留 `caller.kind=external` 的被动传参与边界约束。
