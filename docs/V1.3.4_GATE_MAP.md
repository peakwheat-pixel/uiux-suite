## 3. 版本化聚合规则表（TASK-03 前置，B3）

### 3.1 v1.3.3（legacy，不可变）

| test_state | 对 aggregate_runtime_level 的影响 | 对 coverage_ok 的影响 |
|---|---|---|
| PASS | 取 observed_runtime_level | 不阻断 |
| FAIL | 视为 NONE | 产生 `RUNTIME_TARGET_NOT_COVERED`（若无其他 PASS 覆盖） |
| BLOCKED | 视为 NONE | 同上 |
| UNVERIFIED | 视为 NONE | 使 aggregate 降为 NONE → `RUNTIME_LEVEL_BELOW_REQUIRED` |
| NOT_APPLICABLE | 跳过 | 不阻断 |

### 3.2 v1.3.4（新增，必须实现且测试）

在 v1.3.3 字段不变的前提下，新增可选字段：

```json
{
  "disposition": "ENVIRONMENT_UNAVAILABLE | AUDITOR_OMISSION | TOOL_UNAVAILABLE | FIXTURE_INVALID | NATIVE_INTERACTION_UNAVAILABLE | NOT_APPLICABLE | PRODUCT_FAILURE | EVIDENCE_MISSING | INDEPENDENCE_UNVERIFIED",
  "scope_ref": "<declared scope id, optional>",
  "risk_ref": "<risk item id, optional>"
}
```

聚合规则（新语义，仅 v1.3.4 输入生效）：

| 条件 | aggregate 影响 | delivery 影响 |
|---|---|---|
| 所有 declared scope 内记录 PASS | 取最低 observed level | 可 COMPLETE（若其他 Gate 满足） |
| 存在 `AUDITOR_OMISSION` / `EVIDENCE_MISSING` | 视为 NONE | 禁止 COMPLETE；PARTIAL 且 blocking |
| 存在 `ENVIRONMENT_UNAVAILABLE` / `NATIVE_INTERACTION_UNAVAILABLE` / `TOOL_UNAVAILABLE` / `FIXTURE_INVALID` | 不参与 aggregate 计算（排除），但记录于 `unverified_paths` | 允许“范围化部分完成”；delivery=PARTIAL_SCOPED，不得称完整 |
| 存在 `PRODUCT_FAILURE` | 视为 NONE | 禁止 COMPLETE；FAILED 或 PARTIAL |
| `INDEPENDENCE_UNVERIFIED` | 不参与运行时聚合 | 禁止 `INDEPENDENT_REVIEW_PASS`；可 `ISOLATED_REVIEW_VERIFIED` |
| 高风险项非 PASS（risk_ref 命中高风险） | 强制阻断 COMPLETE | `RISK_GATE_BLOCKED` |
| 通过扩大排除项/删除记录提升状态 | 检出即 FAIL（`SCOPE_MANIPULATION`） | 发行阻断 |

**绝对不得提升为 PASS 的条件**：
1. 无对应 PASS 覆盖记录；
2. evidence 不可解析或哈希不符；
3. observed level < required level；
4. 高风险项无执行证据；
5. 独立性未达到 SPEC §10 要求而声明 INDEPENDENT_REVIEW_PASS。

## 4. A/B/C 级标准（用户指令版）

- **A 级**：全部强制 Gate 通过；declared scope 映射率 100%；高风险无未解决阻断；P0/P1 有充分可复现证据；关键问题独立确认 ≥90%；无重大误归因/虚假 PASS；可机械复算；满足规范要求的独立验收可信来源。
- **B 级**：核心链路真实可用、证据可复核，但覆盖/高风险/独立签发存在已披露限制。
- **C 级**：核心运行、证据完整性、关键归因或主要 Gate 存在不可接受失败。

本轮不预设 A 级；达不到就如实报 B/C。
